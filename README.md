# ChatSphere 💬

A full-stack real-time chat application built with the MERN Stack.

## 🚀 Features

- User Registration
- User Login
- JWT Authentication
- HTTP-only Cookie Authentication
- Protected Routes
- Current User API
- Logout API
- Real-time Chat (Coming Soon)
- Socket.IO (Coming Soon)

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT
- bcrypt
